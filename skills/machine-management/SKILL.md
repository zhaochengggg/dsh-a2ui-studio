---
name: machine-management
description: 登记、查找和维护机器及其 SSH 连接，在机器面板中查看连接状态、说明与应用。适用于机器纳管和定位连接；应用 UI 编写使用 app-cards-authoring。
---

用 machine_list 查目录，machine_inspect 读取详细资料。更新前重新读取 revision，再调用 machine_manage；归档只隐藏记录，不删除机器或卸载服务。重要说明存 notes，长期有意义的变化写 message，不记录例行探测日志。

机器由稳定 ID 标识，IP 变化更新连接，不新建重复机器。允许多条连接，defaultConnection 指定默认项；界面展示实际地址，不要求给每条路径命名。连接指纹须来自可信渠道，不能为绕过冲突而接受现场扫描的新密钥。路径引用私钥，不存密钥内容。

红、绿、灰和加载动画由最近的实际探测决定。详细原因在悬停说明；不把身份冲突混同于认证失败，不把缺少证据说成健康。应用声明引用机器与连接 ID，复用目录的 SSH 身份校验，禁止另建凭据目录。

两个模块属于同一个 dsh-control-studio 插件。登记和档案只由机器模块拥有；应用声明、回执、扩展由应用模块拥有。不要在页面中展示迁移记录和内部存储布局。

Windows 与 POSIX 目标的命令适配由插件执行层负责，不要为使探测通过而修改目标的全局 SSH DefaultShell、安装 Git Bash 或更改 PATH。SSH 已连接但执行检查失败不等于网络不通。档案只写实际核实的信息，不把系统默认值或推测记成事实。不新增人工登记要求。

修改插件后须验证实际运行服务已加载新代码；单独进程调用成功不能当作在线面板已修复。
